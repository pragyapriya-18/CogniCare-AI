# 🧠 CogniCare-AI

An AI-powered cognitive assistance and memory support platform designed for elderly dementia patients.

## 📌 About the Project

CogniCare-AI aims to support elderly people experiencing memory decline and cognitive difficulties through interactive cognitive games, personalized assistance, reminders, and caregiver monitoring.

The platform is designed with a simple, elderly-friendly interface and aims to support multilingual interaction and low-connectivity environments.

## ✨ Key Features

* 🧠 Adaptive cognitive games
* 🎮 Memory, attention, sequence and pattern-based activities
* 🤖 AI-based difficulty adaptation
* 🔔 Medicine and hydration reminders
* 📅 Daily activity and medical appointment reminders
* 📊 Cognitive performance tracking
* 👨‍⚕️ Caregiver monitoring dashboard
* 🗣️ Voice-assisted and multilingual interaction
* 📱 Elderly-friendly mobile/tablet interface
* 📡 Offline functionality and synchronization
* 🔐 Secure patient data management
